# panshulvempalli.vercel.app

Personal site of Panshul Vempalli. React + TypeScript + Vite + Tailwind, deployed on Vercel.

- All content lives in `src/data/content.ts`. Edit that file to update awards, projects and roles.
- Pages: `/`, `/about`, `/achievements`, `/projects`, `/experience`, `/research`, `/cv` (print-ready, use "Download PDF").
- Press ⌘K / Ctrl+K anywhere for the command menu.

```sh
npm install
npm run dev
```
